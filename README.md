# 🦭 阿咩豹的小厨房 · 私人双端同步菜谱

由白绒绒的格陵兰海豹幼崽 **阿咩豹**（戴着厨师帽、系着浅蓝小围裙）帮忙守着的私人菜谱网站，适配 **iPhone 灵动岛 PWA 全屏体验** 与 **电脑桌面宽屏浏览**，支持两人共享同一个家庭密码同步菜谱、成品图与想吃备料清单。

## 主要功能

- **安全家庭暗号解锁**：网页前端不保存任何 GitHub Token，全部通过 Cloudflare Pages Functions 在后台代为读写你的 GitHub 私有仓库。
- **浏览与主厨双模式**：默认处于防误触的「逛菜单」模式；点击右上角切换「主厨模式」即可新增、编辑、删除菜谱。
- **主料 / 调料分栏 & 极速补录**：
  - 支持选中成品照后在浏览器内自动压缩（约 100–250KB），不爆仓库体积。
  - 支持「待补全」草稿状态，方便先把脑子里的 100 多道菜名和成品图快速建档，再慢慢补充细节。
  - 支持批量粘贴或语音转文字后「⚡ 智能拆分成行」（自动分离食材名与用量）。
- **多标签分类 & 食材反查**：一道菜可挂多个标签（如 `肉菜` + `冬季菜` + `拿手菜`），支持多标签交集/并集筛选，也可直接搜主料/调料反查“冰箱剩菜还能做什么”。
- **想吃清单 & 提前备料汇总**：
  - 爱人点下「想吃」后，阿咩豹会翻肚皮比心打滚庆祝，并在云端同步想吃清单。
  - 自动将所有已点菜品的主料与调料合并成一张买菜核对表，支持勾选「已备好」以及临时加购杂项。
  - 做好打卡后记录「阿咩豹投喂次数」。

## 本地预览运行

无需安装任何依赖，只需 Node.js 20+：

```bash
cd ameibao-recipes
node dev-server.mjs
```

打开浏览器访问 `http://127.0.0.1:8788`，本地体验模式默认密码为 `ameibao`（数据保存在本地 `.local-db/`）。

如需正式免费部署到手机与电脑随时互通，请看详细图文文字版指南：[DEPLOY_GUIDE.md](./DEPLOY_GUIDE.md)。
